# Serbia Company Data

> A single-purpose, pay-per-call REST API serving normalized Serbian company registry data and the
> latest public financial-statement summaries, derived from the Serbian Business Registers Agency (APR)
> high-value open data. There is no account, no signup and no API key: priced routes return HTTP 402
> with an x402 v2 payment challenge and settle in USDC on Base. Snapshot of 133,802 companies as of
> 2026-06-30; sole proprietors are excluded. Monetary values are in thousands of Serbian dinars
> (thousand_RSD).

Generated by API Evangelist on 2026-08-09 from the provider's live surface. The provider does not
publish an llms.txt of its own (/llms.txt returns 404).

## APIs

- [Serbia Company Data API](https://serbia-company-x402.vercel.app): Company profile lookup by 8-digit
  registration number, name search in Latin or Serbian Cyrillic, and batch lookup of up to 10 companies.

## Operations

- `GET /api/company?mb=07044275` — `getSerbianCompany` — one company profile. $0.01 USDC.
- `GET /api/search?q=air%20serbia&limit=5` — `searchSerbianCompanies` — ranked name search, limit 1-10 (default 5). $0.01 USDC.
- `POST /api/company/batch` — `batchGetSerbianCompanies` — body `{"registrationNumbers":["07044275","20047216"]}`, max 10. $0.05 USDC.
- `GET /api/sample` — free worked sample response. No payment. Not declared in the OpenAPI.
- `GET /health` — liveness plus dataset provenance metadata. No payment. Not declared in the OpenAPI.

## Specs

- [OpenAPI 3.1](https://serbia-company-x402.vercel.app/openapi.json): three operations, unique operationIds, no components.schemas, no securitySchemes.
- [APIs.json 0.21](https://serbia-company-x402.vercel.app/.well-known/apis.json): the provider's own discovery index.
- JSON Schema 2020-12 documents per route, published inside the x402 bazaar extension of each 402 challenge.

## Payment

- Protocol: x402 v2 over HTTP. Challenge in the `PAYMENT-REQUIRED` response header (base64 JSON),
  signed payload in `PAYMENT-SIGNATURE`, settlement in `PAYMENT-RESPONSE`.
- Scheme `exact` on network `eip155:8453` (Base), asset USD Coin, `maxTimeoutSeconds` 300.
- Buyer setup: [x402 quickstart for buyers](https://docs.x402.org/getting-started/quickstart-for-buyers).
- The 402 fires before input validation, so a malformed request also returns 402 rather than 400.

## Data and licensing

- Publisher: Serbian Business Registers Agency (APR).
- Registration dataset: https://openapi.apr.gov.rs/api/opendata/companies
- Financial-statements dataset: https://openapi.apr.gov.rs/api/opendata/companies/financial-statements
- License: [Serbian Open Data License 1.0](https://data.gov.rs/sr/terms/) (SODL-1.0).
- Two APR whole-dataset snapshots joined on registration number, compacted and normalized. No fields
  added from APR's website or paid services.
- Informational data only. Not legal, tax, credit, KYC/AML or investment advice. Absence from the
  snapshot is not proof an entity does not exist.
